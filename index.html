How the internet works – visualisation spike

The chosen stack (Svelte 5 + SVG) running the mini-scene: phone → Wi-Fi access point → home router → internet, with animated packets. Tap (or pinch/scroll into) the Wi-Fi link to dive into radio waves, or the fibre link to see light pulses and DWDM colours. Switch language (EN / DA / AR) and kid/nerd mode in the top bar.

Spike

Svelte 5 + SVG

Scenes as Svelte components rendering SVG from data; reactive i18n; Svelte transitions.

Deep links: #/<lang>/<scene>, e.g. #/da/wifi or #/ar/fibre. Why this stack was chosen over SVG + GSAP, PixiJS and Three.js: docs/visualisation-spikes.md (the discarded spikes live at git tag spikes/visualisation-v1).
